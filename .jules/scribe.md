## 2026-10-06 - Bulk YAML modifications and formatting
**Learning:** Using a python script with `yaml.dump` to update `docs/openapi.yaml` will completely rewrite the file and discard original YAML formatting choices, such as list indentation (`- item`) and folded text blocks (`description: >`). This creates a noisy `git diff` that violates the directive to "Keep formatting, markdown style, and voice consistent with the existing repository" and make "minimal, targeted updates".
**Action:** When making updates to YAML or markdown files, prefer targeted tools like `sed`, `awk`, or manual `replace_with_git_merge_diff` over full file rewrite scripts (like `pyyaml`'s `dump`) to preserve original formatting and ensure a minimal diff, unless the file specifically requires regeneration.
